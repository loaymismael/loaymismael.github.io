# Loay M. Ismael — Portfolio Website

Personal portfolio focused on healthcare data analysis, health informatics, and a long-term interest in AI in Medicine.

## Current foundation

- Responsive portfolio landing page with project links, services, experience, education, skills, and contact details.
- Light/dark theme toggle, initially following the device preference and remembering manual changes.
- Mobile navigation, project category filters, reduced-motion support, and toast notifications.
- Privacy Policy and Terms of Use.
- Static HTML, CSS, and JavaScript; no build step is required.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then save.
4. Wait for GitHub Pages to finish publishing at https://loaymismael.github.io.

## Important limitations in this first version

The admin dashboard, secure GitHub OAuth, database-backed contact delivery, email notifications, content management, certificate gallery, and visitor map are not implemented yet. The contact form currently prepares an email draft in the visitor's email application; it does not send a message through this website. Portrait, certificate, and handwritten-note source images still need to be added. No custom visitor tracking or location collection is active.

Do not add API keys, OAuth secrets, or service-role keys to this public repository. Any future backend integration must use server-side secrets, verified authorization, abuse protection, and confirmed free-tier limits.
