Hospital Readmission Analytics

A documented portfolio project exploring healthcare data and turning analysis into careful, actionable questions.

Project date: 2026Status: Completed
Open GitHub Repository ↗Back to All Projects

Business Problem

Hospital readmissions are an important measure for understanding care transitions and post-discharge outcomes. This project organizes encounter-level data to explore readmission patterns and related operational measures.

Approach

Built a SQL Server and Power BI analysis using the project dataset, with data preparation, SQL scripts, a dashboard, and a PDF report documented in the repository.

Key Findings

  • The project dataset contains more than 102,000 patient encounters and approximately 72,000 patients.
  • The reported 30-day readmission rate is 11.16%.
  • The reported average length of stay is 4.40 days.

Recommendations

  • Review readmission definitions and denominator rules before comparing results with other institutions.
  • Explore patterns by relevant patient and encounter characteristics, while accounting for limitations in the available data.
  • Use findings to generate questions for multidisciplinary review rather than infer causation.

Business Impact

Provides a documented analytics workflow and dashboard for exploring readmissions and length of stay; no reduction in readmissions is claimed.

Clinical Relevance

Offers a descriptive lens on care transitions. Dataset-level patterns should not be interpreted as individual clinical predictions.

Technologies Used

Microsoft SQL ServerPower BIData CleaningDashboard Design

What I Learned

Clear measure definitions, transparent data preparation, and a report that connects findings to cautious recommendations make healthcare analytics more interpretable.

Interpretation note: results describe the project dataset and its available fields. They should not be treated as causal evidence, individual clinical predictions, or proof of real-world intervention impact.
